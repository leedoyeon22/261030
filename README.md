# 261030 Figma 기반 해외주식 프로토타입

기존 React + TypeScript + Vite 프로젝트를 기반으로 피그마의 화면 흐름을 탐색할 수 있도록 구성했습니다.

## 실행
1. Node.js 20.19+ 또는 22.12+ 설치
2. `npm install`
3. `npm run dev`
4. 표시되는 localhost 주소 접속

## 구현 범위
- 시작, 투자 성향 온보딩/결과, 해외주식 홈, 추천, 검색
- 엔비디아/애플/테슬라/마이크론 상세, 주문, 주문 완료 (공유 템플릿의 종목별 변형)
- 주요 지수 3종 상세, AI 브리핑, 알림함, 소수점 거래
- 커뮤니티 게시글 작성 및 좋아요, 주주 인증 안내, 프로필, 자산, 설정
- 하단 메뉴, 뒤로가기, 관심 종목, 화면 탐색

**주의:** Figma 전체 프레임의 주요 화면/동선에 대응하는 기능형 프로토타입입니다. 모든 레이어를 픽셀 단위로 복제한 것은 아닙니다. 시세/자산/알림은 샘플 데이터이며 실제 매매, 계좌 인증, 실시간 API 연동은 없습니다.

## 2026-10-30 개선본
- 글로벌 투자 SVG 일러스트와 새로운 시작 화면, 데스크톱 탐색 메뉴 및 반응형 모바일 레이아웃
- 종목 아이콘, 미니 차트, 상승/하락 색상, 인기·상승률·관심 탭
- 기간 선택에 따라 바뀌는 예시 차트와 검색 결과 없음 안내
- 투자 성향의 필수 3개 답변 확인 및 관심 분야별 기업 탐색
- 관심 종목·성향·모의 주문의 브라우저 저장, 모의 보유 수량과 자산 금액 집계
- $1~$10,000 소수점 모의 주문과 완료 → 자산 흐름
- 커뮤니티 인기 순 정렬, 실제 인증이 없는 글의 인증 표시 제거

모든 가격, 환율, 지표와 차트는 기존 시연 데이터를 사용합니다. 외부 계좌나 실시간 시세 API는 연결하지 않았습니다. 커뮤니티 글은 현재 화면에서만 유지됩니다.

### 검증
`npm run build`의 TypeScript 검사 및 Vite 빌드 통과. 브라우저 조작 도구의 주소 확인 오류로 수동 화면/클릭 검증은 미완료입니다.
