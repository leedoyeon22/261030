261030 실행 방법 (Windows)

1. Node.js LTS 설치: https://nodejs.org/
2. 이 폴더에서 start-windows.bat 더블클릭
3. 처음 실행하면 npm install이 진행되므로 기다리세요.
4. 터미널에 표시된 주소(보통 http://localhost:5173/)를 브라우저에서 여세요.

직접 실행하려면 VS Code 터미널에서:
 npm install
 npm run dev

종료: 실행 중인 터미널에서 Ctrl+C
참고: 실행 검증은 이 환경에서 의존성 설치 시간 제한으로 완료하지 못했습니다.
